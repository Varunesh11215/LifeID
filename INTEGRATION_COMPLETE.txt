🔌 API INTEGRATION MAP

20 REST Endpoints    6 Middleware Components    4 Page Hierarchies

Authentication Flow:
  1. User login (POST /api/auth/login)
  2. Server returns JWT token
  3. Frontend stores token in state
  4. Subsequent requests include Authorization header
  5. Backend middleware verifies JWT
  6. Route handler processes authenticated request
